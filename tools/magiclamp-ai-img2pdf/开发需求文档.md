# 开发需求文档

## 目标
提供一个图形化入口，选择图片目录后全自动完成处理并合并为 PDF。

## 功能范围
- 选择图片目录作为入口
- 自动按文件名排序
- 处理不同宽度图片，先统一为同宽后再合并
- 无边距合并为 PDF
- 可选 AI 图像清晰修复，修复完成后再合并
- AI 引擎自动下载与准备
- AI 倍率默认自动判定
- 提供一键启动批处理入口
- 提供打开输出目录与打开PDF入口
- AI 默认模式为动漫高清（realesr-animevideov3）
- 通用高清使用 realesrgan-x4plus
- 支持指定 GPU（默认使用 0 号 GPU）
- UI 采用卡片式布局与清晰的信息层级
- UI 采用火山灰主题与反白字体
- 4K 环境下自动 DPI 缩放适配
- UI 固定 4 倍缩放
- UI 外框尺寸同步放大 4 倍
- UI 布局采用左右分区与卡片层级
- 窗口底色为更深火沙灰
- UI 布局对齐目标设计稿
- AI 提供颜色保持选项
- 窗口可调整尺寸并自适应布局
- 输入框长度收紧并与内容匹配
- UI 使用垂直布局并匹配窗口尺寸
- 选择框高度与文字一致
- AI 选择框高度与文字一致
- 增大选择框和复选框尺寸

## 处理规则
- 支持图片格式：jpg、jpeg、png、bmp、tif、tiff、webp
- 统一宽度规则：以最大宽度为目标等比缩放
- 输出 PDF 路径：与图片目录同级，默认与目录同名
- AI 倍率规则：图片宽度小于 1600 使用 4x，否则使用 2x
- PDF 输出优先单页无缝拼接，超大尺寸自动降级为多页无缝
- AI 临时文件写入系统临时目录，任务完成自动清理

## 依赖与前置
- 运行环境：Windows
- 运行依赖：Python 3
- 图像处理依赖：Pillow
- AI 清晰修复依赖：Real-ESRGAN 自动下载
- 启动方式：双击一键启动.bat
