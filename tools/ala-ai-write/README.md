## 📖 Overview

**awpro** (MagicLamp AI Writer Pro) is not just a prompting tool; it is a **full-stack consultative writing skill** designed for Opencode agents. It transforms generic LLM outputs into **CEO-level strategic insights**, adhering to rigorous "anti-AI flavor" standards and deep business logic.

Built for **神灯智库 (MagicLamp Think Tank)**, `awpro` orchestrates complex writing tasks—from 5000-character deep-dive chapters to visual asset generation—while maintaining a consistent, premium, and authoritative voice.

## 🚀 Key Features

*   **Consultative Stance**: Adopts the persona of a Chief Strategy Officer, not a technical manual writer.
*   **6-Block Narrative Structure**: Enforces a logical flow: *Failure of Status Quo -> The Bridge -> Hard Evidence -> Mechanism -> Implementation -> Action*.
*   **Anti-AI Flavor Protocol**: rigorous filters to banish words like "delve", "empower", "unlock", and generic "A vs B" comparisons.
*   **Context Isolation**: Smartly distinguishes between "Part Introductions" (context) and "Chapter Content" (task) to prevent repetitive fluff.
*   **Visual Matrix Integration**: Parallel processing for generating text and corresponding visual 5D prompts (`/awi`).
*   **Auto-Archiving & Versioning**: Intelligent file handling with collision detection (`-aw`, `-aw-aw`) to prevent data loss.

## 🛠️ Command System

Usage via Opencode Slash Commands:

| Command | Description | Example |
| :--- | :--- | :--- |
| **/aw** | **[Core]** Start a deep-dive writing task for a specific chapter. | `/aw 16节-品牌健康` |
| **/awi** | **[Visual]** Generate a 5D visual prompt for image generation. | `/awi A futuristic data center pulsating with light` |
| **/zs** | **[Style]** "Humanize" a specific text block to remove AI artifacts. | `/zs [Paste text here]` |
| **/check** | **[QA]** Run a self-check on logic, word count (>5000), and banned vocabulary. | `/check` |
| **/snapshot** | **[System]** Force save current state to a backup file. | `/snapshot` |

## 🧠 The "Soul" of Consultative Writing

`awpro` is defined by its refusal to be mediocre. It enforces the **"Soul Renaissance"** principles:

1.  **Invisibility**: Structure is hidden. The reader feels a smooth logical flow, not a template.
2.  **Hard Evidence**: No fictional "Manager Bob" stories. Only verifiable, real-world case studies (e.g., Luckin Coffee, Shein, LVMH) from 2024-2026.
3.  **First Principles**: We don't say "Traditional marketing is bad." We explain *why* it fails structurally due to the shift from linear to network propagation.

## 📦 Installation

This skill is designed for the **Opencode** agent ecosystem.

1.  Clone this repository to your agent's skills directory:
    ```bash
    git clone https://github.com/ala2017/ala-ai-write.git
    ```
2.  Refresh your agent's skill index.
3.  Type `/aw` to start creating.

## ⚠️ Compliance & Standards

*   **Output Location**: Strictly enforces saving to the Current Working Directory (`./`).
*   **Banned Vocabulary**: `Empower`, `Unlock`, `Game-changer`, `Elevate`, `Realm`.
*   **Red Lines**: No "A/B comparisons" of fictional scenarios. No copying of "Part Intros" into "Chapter Headers".
