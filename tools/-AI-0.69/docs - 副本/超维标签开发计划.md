# 超维标签开发计划

## 一、开发概述

### 项目背景
超维标签功能是神灯AI书签管理器的AI辅助核心功能之一，用于提供多维度超维标签系统，帮助用户构建知识量子云图，实现高效书签管理。

### 开发目标
基于已完成的模块化架构，完善超维标签功能，实现标签云和关系图谱两种可视化方式，提供超维标签分析能力。

### 开发周期
总计4周，分4个迭代实现。

```typescript
// 书签数据获取
async function fetchBookmarks() {
  return new Promise((resolve) => {
    chrome.bookmarks.getTree((bookmarkTreeNodes) => {
      const bookmarks = flattenBookmarks(bookmarkTreeNodes);
      resolve(bookmarks);
    });
  });
}

// 标签分析请求
async function analyzeBookmarks(bookmarks, batchSize = 100) {
  const batches = [];
  for (let i = 0; i < bookmarks.length; i += batchSize) {
    batches.push(bookmarks.slice(i, i + batchSize));
  }
  
  // 处理进度追踪
  let processedCount = 0;
  const results = [];
  
  for (const batch of batches) {
    const batchResults = await callAIService(batch);
    results.push(...batchResults);
    processedCount += batch.length;
    
    // 更新进度
    updateProgress(processedCount / bookmarks.length);
  }
  
  return results;
}
```

### 2. 标签云布局
```typescript
// 基于权重的布局算法
function calculateTagPositions(tags, containerWidth, containerHeight) {
  const positions = {};
  const centerX = containerWidth / 2;
  const centerY = containerHeight / 2;
  
  // 根据权重决定距离中心的远近
  tags.forEach(tag => {
    const distance = 100 + (10 - tag.weight) * 20;
    const angle = Math.random() * Math.PI * 2;
    
    positions[tag.id] = {
      x: centerX + Math.cos(angle) * distance,
      y: centerY + Math.sin(angle) * distance
    };
  });
  
  // 碰撞检测与调整
  runCollisionDetection(positions, tags);
  
  return positions;
}
```

```typescript
// D3力导向图实现
function createForceGraph(container, nodes, links) {
  const simulation = d3.forceSimulation(nodes)
    .force("link", d3.forceLink(links).id(d => d.id))
    .force("charge", d3.forceManyBody().strength(-200))
    .force("center", d3.forceCenter(width / 2, height / 2))
    .force("collision", d3.forceCollide().radius(d => 20 + d.weight * 2));
  
  // 绘制连线
  const link = svg.append("g")
    .selectAll("line")
    .data(links)
    .enter().append("line")
    .attr("stroke-width", d => Math.sqrt(d.weight));
  
  // 绘制节点
  const node = svg.append("g")
    .selectAll("circle")
    .data(nodes)
    .enter().append("circle")
    .attr("r", d => 10 + d.weight)
    .call(d3.drag()
      .on("start", dragstarted)
      .on("drag", dragged)
      .on("end", dragended));
      
  // 更新位置
  simulation.on("tick", () => {
    link
      .attr("x1", d => d.source.x)
      .attr("y1", d => d.source.y)
      .attr("x2", d => d.target.x)
      .attr("y2", d => d.target.y);
    
    node
      .attr("cx", d => d.x)
      .attr("cy", d => d.y);
  });
}
```
