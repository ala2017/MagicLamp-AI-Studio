# 超维标签功能设计文档

## 一、功能概述

### 1.1 功能定位
- AI辅助功能的核心子功能之一
- 提供多维度超维标签系统
- 支持标签云和关系图谱两种可视化方式

### 1.2 入口设计
- 位置：AI辅助功能页面左侧导航栏
- 触发：点击"超维标签"按钮
- 显示：在头部和左侧按钮以外的主要内容区 quantum-container容器范围内

### 1.3 核心功能
- 超维标签分析
- 标签云可视化
- 关系图谱展示
- 相关书签查询

## 四、交互设计

### 4.1 标签交互
```typescript
class TagInteractionManager {
  // 处理标签点击
  handleTagClick(tag: string) {
    // 更新标签状态
    this.updateTagState(tag);
    
    // 查找相关书签
    const bookmarks = this.findRelatedBookmarks(tag);
    
    // 更新结果面板
    this.updateResultPanel(bookmarks);
    
    // 如果在关系图视图，突出显示相关节点
    if (this.currentView === 'relation') {
      this.highlightRelatedNodes(tag);
    }
  }
  
  // 更新结果面板
  updateResultPanel(bookmarks: BookmarkItem[]) {
    const panel = document.querySelector('.result-panel');
    panel.innerHTML = this.generateBookmarkList(bookmarks);
  }
}
```

### 4.2 关系图交互
```typescript
class RelationGraphManager {
  constructor() {
    this.simulation = d3.forceSimulation()
      .force("link", d3.forceLink().id(d => d.id))
      .force("charge", d3.forceManyBody().strength(-100))
      .force("center", d3.forceCenter(width / 2, height / 2));
  }

  // 节点点击处理
  handleNodeClick(node: TagRelationNode) {
    if (node.type === 'tag') {
      this.highlightRelatedNodes(node.id);
      this.updateResultPanel(node.id);
    } else {
      this.openBookmark(node.id);
    }
  }

  // 更新关系图
  updateGraph(data: {nodes: TagRelationNode[], links: TagRelationLink[]}) {
    // 更新节点和连线
    this.updateNodes(data.nodes);
    this.updateLinks(data.links);
    
    // 重启模拟
    this.simulation.alpha(1).restart();
  }
}
```

## 五、数据处理流程

### 5.1 分批处理机制
- 每批处理100个书签
- 实时显示处理进度
- 动态更新标签云/关系图
- 支持暂停/继续处理

### 5.2 AI分析流程
1. 收集书签数据（标题、域名、目录路径）
2. 按批次发送到AI服务（AI服务为模型选择功能模块中被选中的ai-api）
3. 接收并解析AI返回的标签建议
4. 更新可视化视图
5. 处理用户交互
