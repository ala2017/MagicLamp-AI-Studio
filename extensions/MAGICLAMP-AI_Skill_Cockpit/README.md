# MAGICLAMP·AI Skill Cockpit (v0.0.1)

> **Status**: 🟢 Core Implemented | 🏗️ Alpha Stage
> **Last Build**: Passing (Pre-flight Verified)

The "Universal Command Center" for managing AI Skills, MCP Servers, and Extensions.
Built with **React + Webpack + VS Code Extension API**.

## 🚀 Features

1. **Nav Rail UI**: Dedicated Management Console (React).
2. **Multi-Source**: Fetch skills from Official Manifest AND SkillHub Community.
3. **Orchestration Hub**: Visual workflow builder for CrewAI/AutoGen agents (Alpha).
4. **Headless Tested**: Core logic verified via Node.js simulation.

## 🛠️ Development

1. `npm install`
2. `npm run watch` (or press F5 in VS Code)
3. `npm test`
