## 📋 功能模块

### 1. 服务状态指示器
**位置**：右上角  
**状态**：
- 🟡 检查服务中...（灰色，加载动画）
- 🟢 Suno 服务已连接（绿色）
- 🔴 Suno 服务未连接（红色）

**交互**：
- 自动检测服务状态
- 实时更新连接状态

---

### 2. 生成配置区

#### 2.1 歌词内容
**功能**：
- ✅ 大文本框（高度 160px）
- ✅ 自动同步 Lyrics Studio 的歌词
- ✅ 可手动编辑
- ✅ 字符计数
- ✅ 快捷按钮："使用优化后的歌词"

**样式**：
- 等宽字体（font-mono）
- 深色背景
- 聚焦时高亮边框（primary 色）

#### 2.2 Suno 风格提示词
**功能**：
- ✅ 文本框（高度 96px）
- ✅ 自动同步 Style Director 生成的提示词
- ✅ 可手动编辑
- ✅ 字符计数 + 建议范围（50-150 字符）
- ✅ 快捷按钮："使用 Style Director 生成的提示词"

**样式**：
- 深色背景
- 聚焦时高亮边框（accent 色）

**示例提示词**：
```
A dark aggressive hardcore rap, heavy 808 bass, 
distorted synths, angry male vocals, fast flow, 
rebellious mood, 140 BPM
```

#### 2.3 音乐类型选择
**选项**：
- 🎤 带人声（默认）
- 🎹 纯音乐

**样式**：
- 切换按钮组
- 选中状态：primary 色 + 阴影
- 未选中：灰色背景

#### 2.4 模型版本选择
**选项**：
- V3.5 (chirp-v3-5)
- V4 (chirp-v4)
- V4.5+ (chirp-bluejay)
- V4.5 Pro (chirp-auk)
- V5 (chirp-crow) ⭐ 推荐（默认）

**样式**：
- 下拉选择框
- 深色背景

#### 2.5 生成按钮
**状态**：
- 正常：✨ 生成音乐
- 生成中：🔄 生成中...（加载动画 + 进度文本）
- 禁用：灰色 + 提示文本

**禁用条件**：
- Suno 服务未连接
- 歌词为空
- 风格提示词为空
- 正在生成中

**样式**：
- 渐变背景（primary → accent）
- 大按钮（高度 48px）
- 阴影效果

---

### 3. 生成记录区

#### 3.1 列表头部
**显示**：
- 标题："生成记录"
- 统计："X 个作品"

#### 3.2 空状态
**显示**：
- 大图标（音乐图标）
- 提示文本："暂无生成记录"
- 副文本："点击上方按钮开始生成你的第一首音乐"

#### 3.3 音频卡片
**布局**：
```
┌────────────────────────────────────────────────┐
│ [封面/播放] 标题 [状态徽章]  ❤️ ⬇️ 🗑️        │
│              模型 • 时间                        │
└────────────────────────────────────────────────┘
```

**元素**：
1. **封面/播放按钮**（左侧）
   - 显示封面图（如果有）
   - 或显示默认音乐图标
   - 悬停时显示播放/暂停按钮

2. **标题和状态**（中间）
   - 标题（粗体，可截断）
   - 状态徽章：
     - 🟡 排队中
     - 🔵 生成中（加载动画）
     - 🟢 完成
     - 🔴 失败

3. **元信息**（中间下方）
   - 模型名称
   - 生成时间

4. **操作按钮**（右侧）
   - ❤️ 收藏（点击变红色填充）
   - ⬇️ 下载（仅完成状态）
   - 🗑️ 删除

**交互**：
- 悬停时边框高亮
- 点击播放按钮播放音频
- 点击收藏按钮切换收藏状态
- 点击下载按钮下载到本地
- 点击删除按钮移除记录

## 🎨 设计细节

### 颜色方案
- **Primary**：主色调（蓝紫色）
- **Accent**：强调色（粉红色）
- **Surface**：表面色（深灰）
- **Background**：背景色（更深的灰）
- **Text Main**：主文本（白色）
- **Text Muted**：次要文本（灰色）

### 间距
- 外边距：32px
- 卡片内边距：24px
- 元素间距：16-24px

### 圆角
- 大卡片：16px
- 小元素：8px
- 按钮：8-12px

### 阴影
- 卡片：`shadow-2xl`
- 按钮：`shadow-xl shadow-primary/30`

### 动画
- 淡入：`animate-fade-in`
- 加载旋转：`animate-spin`
- 过渡：`transition-all`

## 🔄 数据流

### 输入数据
```typescript
project: {
    songTitle: string;              // 歌曲标题
    originalLyrics: string;         // 原始歌词
    optimizedLyrics: string;        // 优化后的歌词
    sunoPrompt: string;             // Suno 提示词
    audioGenerations: AudioGeneration[];  // 生成记录
}
```

### 输出数据
```typescript
updateProject({
    audioGenerations: [
        {
            id: string;
            title: string;
            audioUrl: string;
            videoUrl?: string;
            imageUrl?: string;
            status: 'queued' | 'streaming' | 'complete' | 'error';
            liked: boolean;
            createdAt: number;
            model: string;
        }
    ]
});
```

### 消息通信
**发送到 Extension**：
```typescript
// 检查服务
{ command: 'checkSunoService' }

// 生成音乐
{ 
    command: 'generateAudio',
    payload: {
        prompt: string,      // 歌词
        tags: string,        // 风格提示词
        title: string,       // 标题
        makeInstrumental: boolean,  // 是否纯音乐
        model: string        // 模型版本
    }
}

// 下载音频
{
    command: 'downloadAudio',
    payload: {
        id: string,
        url: string
    }
}
```

**接收自 Extension**：
```typescript
// 服务状态
{ 
    command: 'sunoServiceStatus',
    data: { connected: boolean }
}

// 生成完成
{
    command: 'audioGenerated',
    data: AudioGeneration[]
}

// 状态更新
{
    command: 'audioStatusUpdated',
    data: AudioGeneration[]
}

// 错误
{
    command: 'error',
    data: { message: string }
}
```
