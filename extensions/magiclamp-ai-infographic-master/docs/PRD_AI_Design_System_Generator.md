# 商业化级产品需求文档 (PRD)：智能设计系统与哲学生成平台 (暂定名：VibeForge AI / 灵境基因库)

## 1. 产品愿景与定位 (Product Vision)
**定位**：全球首款“反模板化”的「生成式设计资产提炼与工程自动化平台」。
**愿景**：填补非设计专业人员（技术研发、创业者、产品经理）与工业级设计规范（Design System）之间的巨大鸿沟。让任何人都能通过“看图说话和感性问答”，一键生成全球唯一、且能直接投产至研发代码库的完整设计系统体系。

## 2. 核心痛点与市场蓝海 (Pain Points & Market Opportunity)
- **痛点 1（大厂工具的傲慢）**：Figma Variables 和 Style Dictionary 是给专业系统设计师用的，门槛极高，技术小白根本无从下手。
- **痛点 2（现有 AI UI 生成器的鸡肋）**：诸如 v0.dev 等工具，本质是“填空题”，全网共用几套写死的预制皮肤（如 shadcn 默认主题），无法体现用户的私有品牌调性。
- **痛点 3（审美与代码的脱节）**：色彩生成工具（如 Coolors）只能给颜色配置，不能定义诸如动画反馈曲线、圆角空间、H1-H6 缩放律等工程化必需品。

## 3. 核心产品链路 (Core Workflows) - 降维打击的核心理念
本系统将“设计规范”的构建流程拆解为人性化的双轨制输入：

### Phase 1: 多模态美学基因捕获池 (Visual Aesthetic Extraction)
- **用户行为**：用户像建立 Moodboard（情绪板）一样，随意拖拽上传他们喜欢的任何视觉材料。
  - **跨界输入源**：可以是其他 App 的截图、优秀的 Web 界面，甚至可以是杂志排版、电影海报、摄影作品、工业设计图。
- **AI 动作**：利用顶级多模态大模型（如 Gemini 2.5 Pro），对这些离散的图片进行融合抽象分析。
  - 提取色彩法则（不仅是主色，更包含辅助色、灰度计算逻辑）。
  - 提取布局骨架与视觉留白权重。
  - 提取图形与排版的结构张力。

### Phase 2: 交互哲学问诊舱 (Design Philosophy & UX Probing)
- **概念**：“美”是视觉，“哲学”是交互。系统通过智能推演的对话/问卷，探寻用户的交互性格。
- **用户行为**：回答一系列非技术性的感性问题或者进行 A/B 盲测。
  - *例*：“当用户点击完成时，您希望它是‘极其干脆利落’还是‘伴有深呼吸般的弹性反馈’？”
  - *例*：“您希望您的产品给人‘密集的全知掌控感’，还是‘克制的探索感’？”
- **AI 动作**：将人类的感性语言，精准映射为底层工程参数（如 `cubic-bezier` 动画贝塞尔曲线、组件 Density 密度值、毛玻璃模糊半径等）。

### Phase 3: 黑客级资源自动化打包 (Engineering Asset Generation)
- **大一统输出**：AI 将 Phase 1 (视觉) 与 Phase 2 (交互) 融合，生成符合 W3C 标准的 Design Tokens JSON。
- **跨平台交付物**：
  1. 自动化输出完整 `tailwind.config.js` 文件。
  2. 自动化输出 React/Vue 的全局 CSS Variables 和核心样式字典。
  3. 提供可一键导入 Figma 的规范文档脚本。

## 4. 技术架构简述 (Architecture)
1. **Frontend**: React + 丝滑流式动效（渲染诊断式问卷的无缝心流体验）。
2. **AI Core**:
   - `gemini-pro-vision` 负责高维图像反推（Reverse Engineering）。
   - 强约束 Prompt 让大模型固定输出标准化、层级化 Design Token JSON。
3. **Compiler**: 后端集成类 Style Dictionary 的编译逻辑，将 JSON 转化为各种形态的交付代码库。

## 5. 商业变现路径 (Monetization Strategy)
- **B2C (极客/独立开发者模式)**：提供基础的审美诊断，按生成项目次数收费。
- **B2B (企业/初创团队模式)**：高级版团队协作，支持增量生成，自动更新公司全平台的 SDK 包，订阅制 SaaS。
- **Creator Economy (资产交易市场)**：允许有极强审美的用户，将自己淬炼出的“设计哲学 Token 库”挂载在平台上售卖（例如“出售专为金融高管设计的极简奢华数字感 Token 库”）。
