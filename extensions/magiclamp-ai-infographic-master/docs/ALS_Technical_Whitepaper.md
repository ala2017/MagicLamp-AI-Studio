# VibeForge ALS (Aesthetic Logic Synthesis) 技术白皮书 v1.0

## 0. 核心架构逻辑：审美核 (Aesthetic Kernel, AK) 协议

VibeForge ALS 的核心不是生成图像，而是通过多模态大模型（LMM）对个体的感性直觉进行“测序”，生成可编程的数字资产——**审美核 (AK)**。

*   **输入**：非结构化的视觉/听觉参考（用户中意的“那个味儿”）。
*   **处理层**：ALS 映射函数（Aesthetic Mapping Function）。
*   **输出**：一组包含六维灵魂偏置的向量与元数据包（AK 文件）。
*   **价值**：AK 是跨引擎、跨模态的审美指令集，可作为插件注入任何大模型（如 Gemini, Flux, Sora）。

## 1. 模块 I：图像视觉智能 (Visual Intelligence - 已实现/核心)

### 1.1 审美基因提取 (Genetic Deconstruction)
*   **操作层**：利用 `gemini-1.5-pro` 对多张参考图进行“视觉反汇编”。
*   **参数映射**：
    *   **色彩骨架 (C-Matrix)**：不仅是 Hex 值，还包括色域分布、互补逻辑、以及光感的数学定义（Luminance Profile）。
    *   **空间拓扑 (L-Topology)**：提取负空间比例（Negative Space Ratio）、视觉重心导向、以及由于栅格系统决定的“秩序感”。
    *   **情绪微调器 (M-Tuner)**：通过对噪点、质感、边缘锐度的量化，定义图像的“冷/暖、硬/软、工业/自然”等情绪权重。

### 1.2 加权闭环合成 (Weighted Synthesis)
*   **实现方案**：通过“审美不变量定理”，在合成 Prompt 时为不同基因分配权重系数（0.0 - 1.0）。
*   **冲突检测**：ACF (Aesthetic Constraint Fusion) 算法自动过滤掉会导致视觉熵增的冗余指令。
*   **输出引擎**：`gemini-3.1-flash-image-preview`。接收 AK 协议参数，执行高保真渲染。

## 2. 模块 II：时间共鸣智能 (Temporal Resonance/Video - 纲要草案)

### 2.1 视觉基因的随动化 (Motion Property Mapping)
*   **核心逻辑**：将图像中的“质感权重”转化为视频的“帧速率”与“快门角度”。例如：工业硬风格自动对齐至高帧率、低运动模糊。

### 2.2 镜头修辞学定义 (Cinematic Grammar)
*   **纲要**：
    *   基于“人生叙事”锚点自动选择镜头视角（如：疏离感对应长焦/静态；亲密感对应微距/动态）。
    *   **审美核同步**：AK 协议中的色彩偏好自动应用于视频流的 LUT (Look-Up Table) 映射。

## 3. 模块 III：频率谐振智能 (Harmonic Frequency/Music - 纲要草案)

### 3.1 联觉转译算法 (Synesthetic Translation)
*   **核心逻辑**：建立色彩与音色的频率映射阵列。
    *   **明度 -> 采样率/亮度**
    *   **对比度 -> 节奏强度/打击感**
    *   **负空间 -> 减法合成器中的静音/混响深度**

### 3.2 资产化形态
*   **纲要**：AK 协议直接生成 MIDI 控制信号或 VST 插件预设参数，让图像的“味儿”完美转译为听觉的“场”。

## 4. 商业化与资产化路径 (Assetization)

### 4.1 个人审美仓库 (Private Gene Vault)
*   **持久化**：用户所有的分析结果被向量化存储，形成个人专属的“审美资产负债表”。

### 4.2 巨头接口协议 (Lobster/龙虾模式)
