# AI 信息图生成引擎 & 视觉逆向工作室 - 产品需求文档 (PRD)

## 1. 产品愿景与定位
打造一款能够引发**“Wow Moment（惊呼时刻）”**的设计极客工具。不仅提供高质量的“长文本转无门槛信息图”的稳定生产力，更进一步提供突破思维盲区的**“视觉设计逆向工程”**能力。目标是成为最高效的商业展示与灵感变现引擎。

---

## 2. 核心业务模块与功能

### 2.1 模块 A：结构化文本驱动生成（稳定版 / 工作流状态）
该模块已完全跑通，作为用户的核心工作流，具有高度稳定性和防爆机制。

*   **智能文本防护**：源文本框限制最大 3000 字，自动截断超长废话，带有物理字数指示器。
*   **智能解耦机制 (省币+加速)**：
    *   利用低成本快速大脑（`gemini-2.5-flash`）进行一次性分析提炼，并缓存至前端工作流。
    *   只要源文本和密度设定不变，无限次更换视觉风格和版式都不会造成重新消耗大模型文本 Token。
*   **信息密度无级变速 (Information Density)**：
    *   `低 (海报模式)`：抓取极限金句，极致留白，适合单页宣发。
    *   `中 (图文均衡)`：提取 3-5 点核心摘要，适合常规博客/报告插图。
    *   `高 (硬核细节)`：开启微缩排版（Micro-typography）指令，强行提取具体数据、百分比和行业黑话，布局 8-12+ 知识节点，生成高密度的专家级硬核图表或数据看板。
*   **中英双语特化**：强制模型以流畅自然中文输出，但保留高逼格英文原版专业名词（术语）。
*   **物理视觉微调面板**：提供预设极品布局库（Layouts）、风格图库（Styles）、以及画幅比例和分辨率配置（1K/2K/4K）。最终交由最强作图模型 `gemini-3.1-flash-image-preview` 渲染。

### 2.2 模块 B：视觉基因逆向引擎（核心功能已跑通 / 迭代优化中）
颠覆传统的改稿和生图方式。允许用户直接投喂一张神级设计图，由 AI 将其剥离、拆散，然后再灌入用户自己的文字重生。

*   **核心链路**：
    1.  **参考图投喂区**：已上线。支持多格式、拖拽上传，并有占位符状态感知。
    2.  **基因解构分析**：已上线。由于采用了高精度的视觉分析指令（Prompt Engineering），系统可精准剥离色彩（Hex Code）、版式结构、字体情绪及图形风格。
    3.  **基因筛选仪表盘 (The Gene Swatches)**：已上线。提供 100% 色彩保真的交互选择器，用户可以挑选、剔除特定的美学属性。
    4.  **基因仓库 (Gene Vault)**：已上线。利用本地存储持久化用户的“审美战利品”，支持随时提取和复用。
    5.  **终极融合渲染**：已上线。将离散的文字分析与逆向获取的设计参数，动态编译为复合式的出图指令。

## 3. AI 模型调度与技术架构
*   **API鉴权层**：彻底拥抱 AI Studio 内置授权拦截，规避前端越权的 API 报错弹窗并自动恢复状态。
*   **前端框架**：React + Vite + TailwindCSS + Shadcn UI 组件库。利用 LocalStorage 模型缓存历史基因。
*   **模型大脑矩阵**：
    *   「文本处理员」-> `gemini-1.5-flash` (极致速度与提炼理解)
    *   「视觉提款机」-> `gemini-1.5-pro` (像素级逆向工厂：针对设计稿进行视觉反汇编)
    *   「视觉渲染器」-> `gemini-3.1-flash-image-preview` (也就是 Nano Banana 2，强无敌的神级视觉出图)

## 4. 后续演进阶段图 (Roadmap)
*   **Phase 1** (已完成): 文本驱动生成流程 100% 跑通。
*   **Phase 2** (已完成): 视觉逆向引擎（读图分析 + 前端基因库交互）核心链路闭环。
*   **Phase 3** (当前 / 正在打磨): 提升颜色提取的“视觉张力”与“保真度”，优化长距离文本与复杂排版的适配性。
*   **Phase 4** (下一步):

    *   **多轮基因修正**：基于对话的视觉细节二次微调（例如：“绿色再亮一点”、“把这种排版换成更紧凑的”）。
    *   **UI 完全整合**：将两个模块升级为沉浸式的、完全响应式的专业生产力界面。
