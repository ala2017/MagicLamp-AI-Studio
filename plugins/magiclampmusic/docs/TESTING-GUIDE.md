## 🎯 测试前准备

### 1. 环境要求

**必需**：
- VS Code 1.80+（或 Cursor, Windsurf, Antigravity）
- Node.js 18+
- 工作区文件夹（用于存储项目）

**可选**：
- Gemini API Key（如果不在 Antigravity 中）
- Suno 账号 + suno-api-private 服务

### 2. 安装插件

```bash
# 1. 确保已编译
npm run compile
cd webview && npm run build

# 2. 在 VS Code 中按 F5 启动调试
# 或者打包安装
npx vsce package
code --install-extension magiclampmusic-0.0.1.vsix
```

### 3. 配置 Suno 服务（可选）

如果要测试音乐生成功能：

```bash
# 克隆 suno-api-private
git clone https://github.com/joeseesun/suno-api-private
cd suno-api-private

# 安装依赖
npm install

# 配置 Token
node setup-cookie.js

# 启动服务
npm start
```

## 🐛 已知问题

### 1. Gemini API 限制

**问题**：Gemini API 有速率限制

**影响**：频繁调用可能失败

**解决方案**：添加重试机制和缓存

---

### 2. Suno Token 过期

**问题**：JWT Token 会过期（几小时到几天）

**影响**：生成失败，返回 401 错误

**解决方案**：提示用户重新配置 Token

---

### 3. 音频下载慢

**问题**：音频文件较大（约 5-10MB）

**影响**：下载需要时间

**解决方案**：显示下载进度
