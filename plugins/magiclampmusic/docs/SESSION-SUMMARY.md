
### 关键技术决策

1. **状态管理**：选择 Zustand（轻量、简单、TypeScript 友好）
2. **消息通信**：类型安全的消息协议（TypeScript 联合类型）
3. **AI 适配**：工厂模式 + 策略模式（优先内置，降级到用户配置）
4. **网络请求**：使用 Node.js 原生 https 模块（避免 fetch polyfill）
5. **数据持久化**：文件系统 JSON（简单可靠）

## 🐛 遇到的问题与解决

### 问题 1：Webpack 配置错误

**问题**：`path-browserify` 依赖缺失

**解决**：移除不必要的 `fallback` 配置

**文件**：`webpack.config.js`

### 问题 2：TypeScript 类型错误

**问题**：`globalState.get()` 返回 `unknown` 类型

**解决**：使用 `as any` 类型断言

**文件**：`src/extension.ts`

### 问题 3：fetch API 不可用

**问题**：Node.js 环境中没有 `fetch` 全局函数

**解决**：使用 Node.js 原生 `https` 模块重写 Gemini 适配器

**文件**：`src/services/adapters/geminiAdapter.ts`

### 问题 4：uuid 类型定义缺失

**问题**：`uuid` 模块没有类型定义

**解决**：安装 `@types/uuid`
