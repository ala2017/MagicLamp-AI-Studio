# MagicLamp AI Studio

**神灯AI工作室** — 神灯智库旗下软件开发单元

> VS Code extensions · opencode skills · apps & utilities

## Structure

```
MagicLamp-AI-Studio/
├── extensions/   ← VS Code / Chrome 插件（安装在宿主平台中）
├── skills/       ← opencode / Claude skills（被 AI agent 加载）
├── apps/         ← CLI / 桌面 / Web / 脚本（用户直接运行）
└── AGENTS.md     ← IDE 自动遵循的项目规范
```
