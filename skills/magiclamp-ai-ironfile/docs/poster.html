六种死亡场景

AI 编辑文件会失败，至少有六种不同的死法。而你不需要记住这些——IronFile 替你记住了。

01

Token 耗尽断

单次会话 token 预算用尽，文件写到一半被截断或零清空。
Claude Code — 5,636 行永久消失。

[FILE CORRUPTED]
02

Agent 用错工具

AI 在 Write / Edit / Bash 之间误操作——覆盖、插入错位、重定向覆盖。
AI 不知道自己出错了。

[TOOL MISMATCH]
03

上下文压缩丢状态

窗口压缩后 AI 基于过期的文件认知继续编辑，用不存在的 old_str 去替换。

[STATE LOST]
04

会话中断

浏览器崩溃、系统关机、误关窗口——每次中断都是一次截断抽奖。

[SESSION DEAD]
05

工具自身有 Bug

Kiro 50 行截断、Trae 重启丢历史、Codex 沙箱绕过漏洞——不是你的问题。

[VULNERABILITY FOUND]
06

并发会话互踩

两个 AI session 同时编辑一个项目，后写入的覆盖先完成的。静默丢失。

[RACE CONDITION]
