## 二、问题定义

### 2.1 现有Skill的核心问题

**问题1：无节制的提问**
- 现状：Skill鼓励多角度提问，没有限制
- 痛点：用户被大量问题淹没，无法聚焦
- 影响：效率低下，用户疲劳

**问题2：信息未穷尽**
- 现状：提问前不进行信息收集
- 痛点：问了很多项目说明里已有的问题
- 影响：浪费时间，降低信任

**问题3：问题零散**
- 现状：提问是零散的，没有合并
- 痛点：用户选择一个，其他问题丢失
- 影响：审阅不完整

**问题4：缺乏工具化支持**
- 现状：只是文字指令，没有工具
- 痛点：重复工作，缺乏自动化
- 影响：效率低，可复制性差

### 2.2 用户痛点总结

| 痛点 | 严重度 | 影响 |
|------|--------|------|
| 被大量问题淹没 | 🔴 高 | 效率低，疲劳 |
| 重复问已有信息 | 🔴 高 | 浪费时间 |
| 问题无法聚焦 | 🟡 中 | 审阅不完整 |
| 缺乏自动化工具 | 🟡 中 | 效率低 |

## 三、解决方案设计

### 3.1 核心原则

**原则1：分析优先（Analysis First）**
- 提问前必须进行信息收集
- 尝试自问自答可解答的问题
- 只保留真正无法解决的1-2个核心问题

**原则2：提问克制（Question Frugality）**
- 单轮交互最多3个问题
- 零散问题自动合并
- 一次只提一个核心问题

**原则3：智能辅助（Smart Assistance）**
- 自动扫描可用材料
- 自动生成问题清单
- 自动合并相似问题

**原则4：深度洞察（Deep Insight）**
- 评分体系（价值、逻辑、风险、优化）
- 前沿理论框架（多层次攻防）
- 开源工具特性（工具注册、自动生成）

### 3.2 方法论框架

**借鉴日本AI安全研究所的三层次模型**：
- 战术层：具体问题分析
- 操作层：流程审查
- 战略层：根本原因定位

**借鉴AVID的四步框架**：
- 识别（Identify）
- 设计（Design）
- 执行（Execute）
- 分析（Analyze）

**整合OpenCode的具体场景**：
- 书籍审阅
- 代码审查
- PRD评审
- 学习路径规划

## 四、功能规格

### 4.1 核心功能

**F1：信息收集器**
- 自动扫描项目说明、源文件、文档
- 提取关键信息
- 构建知识图谱

**F2：问题生成器**
- 基于信息自动生成潜在问题清单
- 分类问题类型（逻辑、风险、价值等）
- 评分问题优先级

**F3：问题合并器**
- 识别相似问题
- 自动合并零散问题
- 提取核心矛盾

**F4：审查工具箱**
- 价值度评分工具
- 逻辑链评估工具
- 风险雷达工具
- 优化建议生成器

### 4.2 交互流程

```
用户请求：红队审阅X
    ↓
Step 1：信息收集（自动）
    ↓ 扫描文档、源码、配置
Step 2：问题生成（自动）
    ↓ 5-10个潜在问题
Step 3：问题合并（自动）
    ↓ 2-3个核心问题
Step 4：深度分析（自动）
    ↓ 评分 + 建议
Step 5：输出报告（自动）
    ↓ 1个清晰问题 + 分析报告
```

### 4.3 输出格式

**标准输出**：
```markdown
## 红队审阅报告

### 核心问题
[1个核心问题]

### 分析
- 价值维度：[评分]
- 逻辑维度：[评分]
- 风险维度：[评分]
- 优化维度：[评分]

### 建议
- 优先级1：[具体建议]
- 优先级2：[具体建议]
```

## 五、技术架构

### 5.1 参考设计：Promptfoo工具注册

**借鉴点**：
- `registerRedteamTool()` 模式
- 动态工具注册
- MCP Server架构

**MagiclampAI版本**：
```python
class RedteamToolRegistry:
    def __init__(self):
        self.tools = {
            'value_scanner': ValueScanner(),
            'logic_checker': LogicChecker(),
            'risk_radar': RiskRadar(),
            'optimizer': Optimizer()
        }

    def register(self, name: str, tool):
        self.tools[name] = tool

    def run(self, prompt: str):
        # Step 1: 信息收集
        info = self.collect_info(prompt)
        # Step 2: 问题生成
        questions = self.generate_questions(info)
        # Step 3: 问题合并
        core_issue = self.merge_issues(questions)
        # Step 4: 深度分析
        analysis = self.analyze(core_issue)
        # Step 5: 输出
        return self.format_output(analysis)
```

**集成方式**：

- 支持文件操作（分析后修改）
